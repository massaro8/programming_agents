# Release history

## 0.1.0 — initial public release (prepared, not published)

- Bundled Python minimal, application and service profiles.
- Safe initialization, structural doctor and detachable maintenance metadata.
- Local work registry, skills/evaluations, complexity/risk routing, optional hooks and continuity.
- No generated application runtime dependency on AgentReady, account or backend.

This is an early public version. Adoption, updates, remote templates, model execution and token
telemetry are outside its scope. Numerical token savings have not been established.

Release date and publication are recorded only after the human release procedure completes.
