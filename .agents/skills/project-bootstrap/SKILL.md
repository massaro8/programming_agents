# Project Bootstrap

## Procedure
1. Read the project brief/product spec.
2. Choose the simplest adequate architecture.
3. Create only the directories/capabilities required by the first vertical slice.
4. Establish repository knowledge and validation before feature breadth.
5. Build a walking skeleton.
6. Prove baseline checks.
7. Report assumptions and intentionally deferred capabilities.

## Purpose
Use when initializing a new repository or implementing the initial AgentReady product scaffold.

## Scope

## Verification

## Failure / escalation
