# Agent Definition of Done

A task is DONE only if:

1. requested behavior is implemented;
2. relevant checks were actually executed;
3. outcomes/exit status are available as evidence;
4. changed behavior has appropriate tests;
5. the diff was reviewed for unrelated changes;
6. no conflict marker or temporary artifact remains;
7. dependency/security implications were reviewed when relevant;
8. affected documentation/contracts were reviewed;
9. architecture-impacting decisions were recorded when needed;
10. residual risks and unverified assumptions are explicit.
