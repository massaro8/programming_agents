# Operating Principles

1. Understand before edit.
2. Search before broad read.
3. Define verification before implementation.
4. Use the minimum coherent diff.
5. Put permanent knowledge in repository artifacts, not chat history.
6. Put repeatable procedures in workflows/skills.
7. Put verifiable invariants in deterministic checks/CI.
8. Escalate context, model strength, and validation only when complexity/risk justifies it.
9. Prefer one lead agent; use subagents to isolate noisy read-only work.
10. Evidence beats a model's claim that work is complete.
