# AgentReady 0.1.0

Initial public version of the detachable, vendor-neutral Python repository engineering layer.

- Three bundled profiles: minimal, application and service.
- Trusted init, structural doctor and safe detach.
- Local work lifecycle, skills, advisory complexity/risk routing, optional hooks and checkpoints.
- Generated applications require no AgentReady runtime, account or backend.

This is an early public version. Adoption, updates, remote templates and model execution are outside
its scope. Context-efficiency guidance is not a numerical token-saving claim.

Download the wheel and follow the repository README; PyPI availability is not assumed.
