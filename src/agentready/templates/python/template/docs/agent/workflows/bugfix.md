# Bugfix workflow

Select one READY BUGFIX item. REPRODUCE → LOCALIZE → CONFIRM ROOT CAUSE → ADD REGRESSION TEST → MINIMAL FIX → TARGETED VERIFY → NEIGHBORING VERIFY → evaluate documentation impact → record root cause and verification → complete changelog → DONE → sync registry → stop.

Do not use speculative patch loops. If reproduction, expected behavior, or root cause cannot be established, record the blocker, mark BLOCKED, and stop.
