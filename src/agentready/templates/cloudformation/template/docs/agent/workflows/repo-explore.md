# Repository exploration workflow

Input: a question about an unfamiliar area or the ownership/location of behavior. Read the codebase
map, search for the named symbol, path, or behavior, then inspect only the matching implementation,
contracts, and neighboring tests. Follow imports/callers only as evidence requires. Report the
likely owning capability, relevant paths and symbols, observed boundaries, and uncertainties; do
not edit files. Done when the question has a path-backed answer or a precise unresolved blocker.
